# v0.3 开发增量：文本到训练批次

当前发布基线是 v0.2.0。本增量交付多课程基础和第二课，尚不代表 v0.3 的全部核心模型课程完成。

## 实现范围

- 课程注册表、课程选择与 URL 定位；SQLite 和查询缓存按课程及版本隔离。
- 第二课三个步骤：分词、批次、右移目标。配套图解、源码锚点、知识资料、关系网络、预测题和回顾。
- 新增固定 SHA 的 tokenizer、dataset、dataloader 原始快照及校验和，保留上游 MIT 声明。
- `data-trace` CPU 实验：原创文本、280 项教学词表、临时 Parquet、真实上游批次组装和目标切片；T 支持 8、16、32。
- 实测编码、解码验证和输入/目标保存为有界 `dataTrace`；不训练 GPT，不下载生产数据集。
- 第一课记录兼容；验收要求主动选择同课程同版本 B=2/T=8 的成功任务，解释仍可留空。

## 验证命令

```sh
pnpm check
pnpm test:e2e
pnpm experiment:setup
pnpm experiment:verify --data
```

Python 环境中运行 `python -m pytest runner/tests -q`。CI 同时验证原有前向实验和新增数据实验，保存 CPU 证据。浏览器自动化使用明确标注的测试数据，不作为真实 nanochat 运行证据。

### 2026-09-21 本机结果

- `pnpm check` 通过，含 24 项单元测试；3 项浏览器验收通过。
- CPU Docker 镜像构建成功；容器环境 12 项 Python 测试通过，包括真实 GPT 前向与新课 T=8/16/32。PyTorch 提示未安装可选 NumPy，本课不使用 Tensor/NumPy 转换，测试通过。
- `pnpm experiment:verify --data` 验证真实结果契约；词表 V=280、BOS=271、B=2/T=8，编码后的整段文本可还原。
- `scripts/container-smoke.ts --data` 验证启动、取消、服务重启后的结果保留与活动任务中断。一次 CPU 实测为 0.0135 s，仅计分词、组批与切片，不含 Python 导入，不作为普遍性能承诺。
- Playwright 在实际容器页面启动新实验并查看实测回放；桌面 1366×768、窄屏 390×844、源码和关系网络跳转经过检查。
- 原生 WSL 环境准备先遇到启动超时，后因依赖下载缓慢主动停止；不标记为本轮原生环境验证通过。交付入口是容器。远程 Tutor API 本轮未配置实调，仍保留无 Key 降级。

本机独立 CPU 预览容器为 `llm-phase3-preview`，端口 `127.0.0.1:4312`，卷 `llm-phase3-preview-data`，设置 `restart: unless-stopped`。原有 `4310` 学习服务与数据库保持原状。两个学习库暂不合并。
