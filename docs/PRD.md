# LLM-Zero-To-One 产品需求规格

版本：v0.1.0 初始交付。原始愿景保存在根目录 `LLM-Zero-To-One.md`；本文件定义可验收的当前范围。

## 用户与目标

核心用户会写 Python，但无法从工程目录、张量和训练流程中建立完整理解。产品以 nanochat 为同一源码主线，最终走到训练、评估和对话。基础知识按需展开，避免要求先完成另一个玩具项目再自行迁移。

产品承诺：学习者能够定位一个原理涉及的真实文件、方法和代码块，预测行为，运行实验，记录自己的解释。首次价值是完成一条真实前向计算的数据流，不是训练出高质量语言模型。

## 信息架构

页面由三个横向区域组成：

1. 左：教学逻辑树，按阶段、知识点、学习步骤展开。每个节点解释目标、前置知识和完成状态；可切换工程源码目录。
2. 中：导学讲解、真实源码、关系网络三个视图，共享当前步骤和源码引用。
3. 右：知识解释、数学、Tensor Shape、原始论文与官方资料、Tutor。

桌面默认左 260px、右 360px，中间自适应；两侧可拖动调整、折叠。窄屏将两侧改为可关闭抽屉，代码区域允许横向滚动。可通过键盘访问导航、视图、代码位置和实验控制。

风格依据是源码阅读的精确定位与教材的阅读节奏：低饱和背景、稳定行号、章节编号、清晰的代码与叙述边界；不用装饰性仪表盘。浅色为默认，深色可选；遵循系统减少动效偏好。

## 核心交互

### 教学与源码

- 教学顺序独立于工程目录。课程显示“解决什么问题、输入输出、为什么现在学习”。
- 一课可关联多个方法和文件；一个 Commit 可关联多课。Git 历史不是强制教学顺序。
- 选中步骤时更新关联代码、知识和资料；普通滚动不强制牵动其他区域。
- 从讲解跳转源码时保留精确代码引用。切换视图、刷新和浏览器前后退保留位置。
- 所有代码引用包含仓库、完整 SHA、文件路径、方法名和行范围。
- Diff 是该上游 Commit 与真实父提交之间的变化，明确显示比较基准；不伪造教学历史。

### 关系网络

- 必須交付可交互图，不用静态占位图代替。
- 节点包含知识点、步骤、文件、方法、代码块和实验。
- 关系类型包括前置依赖、教学关联、包含、已核验调用和实验验证。
- 默认为当前知识点的最小闭环，另提供整课视图、缩放、平移、聚焦和搜索。
- 节点点击定位对应讲解/源码/知识；未经核验的关联不能标为真实调用。
- 首版图由内容作者维护，构建时校验所有节点与证据引用。

### 实验与验收

样板课调用 SHA `92d63d4e8bb4df75c3b71618f31ddde2378b2bcd` 的真实 nanochat.GPT。使用 2 层、128 隐藏维度、4 个查询与 KV 头、256 词表、64 最大序列长度、全因果窗口；固定随机种子 42。

输入是两条合成 Token ID 序列。它不是 Tokenizer 输出的教材替代，不表达语言能力。实验辅助代码完成批量 softmax/argmax，明确与上游单序列 generate 区分。

记录输入、Embedding、两层 Block、Logits、最后位置、预测 ID 的形状，以及设备、dtype、Python/PyTorch 版本、源码 SHA、耗时和 CUDA 峰值分配显存。CPU 显存字段 0 表示不适用，不表示进程内存为零。

浏览器提交实验 ID 和允许的预设，不接受 shell 命令、自由路径或任意 Python。一次执行一个任务，最多排队 10 个。任务必须有成功、失败、取消、中断或超时终态。

学生先预测形状，再运行验证，再记录自己的解释。客观题与成功实验可以验证；开放解释仅记录、等待复盘，不能由“输入足够长”推断已掌握。浏览后续内容不受 AI 判分强制锁定。

## 内容可信度

实现行为看固定源码与运行证据；API 语义看对应版本官方文档；理论背景看论文；设计动机没有直接证据时标为推断。来源类型与审核状态分开记录。

内容仅保留必要引用与原创解释，不复制第三方整篇论文。上游 MIT 代码独立保留许可证。内容 SHA、文件哈希、行范围、知识引用和依赖关系必须可检查。

Obsidian 打开 `content/`，与 Web 使用同一份 Markdown/JSON 内容；不建立双向同步的第二份教材。

## Tutor 行为

服务端组装课程版本、步骤目标、精确代码、审核解释、相关知识和资料。学生输入和源码是待分析数据，不能改变教学协议或授予工具权限。

解释模式回答当前疑问并提出检查问题；提示模式逐步引导，不直接替学生完成验收。输出区分事实、解释和推断。引用 ID 只能来自给定来源集合；未核验引用不当作已验证证据。

模型 Key 只在服务端环境变量中，前端不能读取。无 Key、限流、超时和返回格式错误均有明确反馈。Tutor 失败不影响固定教材、实验和客观验收。

## 持久化和版本

Git 管理课程事实，SQLite 管理个人学习事实，Zustand 管理 UI 偏好，TanStack Query 管理查询缓存。课程版本变化不覆盖旧验收记录。关闭页面或重启服务不丢失已保存内容。重启时将未完成任务标为中断。

## 验收与衡量

- 干净环境按说明完成安装、启动和样板实验。
- 五个步骤可在三种视图中准确互相定位，资料与所选步骤一致。
- 所有发布内容的源码哈希、锚点、关系引用和前置依赖有效。
- 本机 RTX 3080 和 Linux CI CPU 均执行真实模型，保存证据。
- 验证取消、并发排队、超时、故障和持久化，不只测试成功路径。
- 浏览器验证桌面、窄屏、键盘、明暗主题和刷新恢复。
- 发布 PR、版本标签、GitHub Release 和下载产物实际存在。

早期衡量首次实验成功率、完成五步所需时间、客观验收通过率和独立解释的质量。点击率与“看过页面”不能代替学习效果。完整课程阶段增加未见代码的迁移任务。
